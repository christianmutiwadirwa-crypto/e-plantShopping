# Paradise Nursery Shopping Application

An online houseplant shop built with React, Redux Toolkit, and Vite. Browse 18 plants across three categories, add plants to a cart, adjust quantities, and view a live order total.

## Overview
Paradise Nursery is a dynamic web application for an online plant shop. The application provides a functional, user-friendly e-commerce experience where users can browse a variety of houseplants, view product details, and manage a shopping cart. 

## Features
* **Product Catalog:** Browse unique houseplants organized by categories, complete with images, names, descriptions, and prices.
* **Interactive Cart:** Add plants to the shopping cart, adjust item quantities, and remove items as needed.
* **Dynamic Updates:** Real-time updates for cart item counts and total cost calculations.
* **Navigation:** Seamless navigation between the home, product listing, and shopping cart pages.

## Run locally

```bash
npm install
npm run dev
```
